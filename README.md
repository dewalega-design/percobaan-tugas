# Tugas Slicing Website - Portfolio Pribadi

**Nama:** Liga Perkasa Dewa
**Instansi:** Universitas Jember (UNEJ)

Repositori ini berisi hasil pengerjaan tugas slicing website portfolio pribadi. Website ini dibangun dari awal untuk memenuhi kriteria tugas tanpa menggunakan framework CSS, dengan fokus pada tampilan yang responsif dan interaktif.

## 🚀 Teknologi yang Digunakan
- **HTML5:** Struktur semantik website (header, nav, section, footer).
- **CSS3 (Murni):** Styling, layouting (Grid & Flexbox), variabel warna, dan media queries (tanpa Tailwind/Bootstrap).
- **JavaScript:** Manipulasi DOM untuk Hamburger Menu pada navigasi mobile dan efek teks dinamis secara berkala pada Hero Section.

## 📱 Fitur Utama
- **Responsive Design:** Tampilan dapat menyesuaikan dengan baik di perangkat Mobile, Tablet, dan Desktop.
- **Interactive Navbar:** Hamburger menu yang dapat di-toggle (buka/tutup) pada ukuran layar kecil.
- **Dynamic Text:** Teks yang berubah otomatis dan memiliki efek *fade* menggunakan JavaScript `setInterval`.
- **Smooth Scrolling:** Navigasi yang meluncur mulus saat berpindah antar bagian (section) website.
